# Untwists

Given a local algebra of rank $n+1$ corresponding to an additive action $\phi$ on $\mathbb{P}^n$, this code computes the birational automorphism of $\mathbb{P}^n$ which untwists the $\iota$-action (the unique additive action on $\mathbb{P}^n$ fixing the complement of the open orbit pointwise) into $\phi$.

## Reference:

- [Arzhantsev, *On conjugacy of additive actions in the affine Cremona group*](https://arxiv.org/abs/2308.12096).
